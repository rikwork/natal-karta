## 📱 Как протестировать приложение:

### Шаг 1: Установите Expo Go
- **Android**: [Скачать из Google Play](https://play.google.com/store/apps/details?id=host.exp.exponent)
- **iOS**: [Скачать из App Store](https://apps.apple.com/app/expo-go/id982107779)

### Шаг 2: Подключитесь к приложению
1. Откройте Expo Go на телефоне
2. Убедитесь, что телефон и компьютер в одной Wi-Fi сети
3. Отсканируйте QR код, который покажет Expo (если есть)
4. Или введите URL: `exp://192.168.1.5:8081`

### Шаг 3: Альтернативный способ
Если QR код не работает, можно:
1. Открыть Expo Go
2. Нажать "Enter URL manually"
3. Ввести: `exp://192.168.1.5:8081`

## 🔧 Если что-то не работает:

### Проблема: "Couldn't connect to server"
**Решение**: Проверьте, что Rails сервер запущен:
```bash
curl http://192.168.1.5:3000/up
# Должен вернуть зеленую страницу
```

### Проблема: "Metro bundler not found"
**Решение**: Перезапустите Expo:
```bash
cd /Users/nikita/projects/natal_karta/NatalKartaExpo
npx expo start
```

### Проблема: "Network request failed"
**Решение**: Проверьте IP адрес в файле `src/services/api.ts`:
```typescript
const API_BASE_URL = 'http://192.168.1.5:3000/api/v1';
```
